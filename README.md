# 컷메이트 · CapCut Agent

Windows에서 영상을 분석하고, **캡컷에서 이어서 수정할 수 있는 초안 프로젝트**를 만드는 로컬 편집 도구입니다. 캡컷 UI를 원격 조작하는 프로그램은 아닙니다.

## 사용하기

1. Windows에 **Python 3.11 또는 3.12**와 **FFmpeg / FFprobe**를 설치하고 PATH에 추가합니다. PowerShell에서 아래 명령을 사용할 수 있습니다.

   ```powershell
   winget install --id Python.Python.3.12 -e
   winget install --id Gyan.FFmpeg -e
   ```

   설치 후 새 터미널에서 `py --version`, `ffmpeg -version`, `ffprobe -version`을 확인하세요.
2. 이 저장소 폴더의 `start-windows.bat`을 실행합니다. 첫 실행 시 Python 가상 환경과 의존성을 설치합니다. 서버가 시작되면 브라우저에서 `http://127.0.0.1:8765`를 엽니다. 이 주소는 내 PC에서 실행한 앱의 주소입니다.
3. 영상을 선택하고 **자동 편집 시작**을 누릅니다. 기본 언어는 한국어, 자막 모델은 `base`입니다. CPU만으로 동작하며, 긴 영상은 시간이 걸립니다.
4. 컷 후보, 자막 문구와 시간, 효과음 종류·음량을 검토합니다. 시간 입력은 **원본 기준 초 단위**입니다. 무음은 기본 선택되고 정지 화면은 기본 보존됩니다. **정지 구간 선택**을 누르면 정지 후보를 한 번에 자동 컷 대상으로 지정합니다.
5. **캡컷 프로젝트 만들기**를 누르면 컷을 적용한 미리보기와 프로젝트 ZIP, SRT를 생성합니다. 수정 후에는 다시 생성하세요. 미리보기의 자막은 브라우저에 표시되는 오버레이이며 MP4에 구워 넣지 않습니다.
6. ZIP을 풀고 **캡컷을 완전히 종료**합니다. 캡컷 설정에서 실제 초안 저장 위치를 확인한 뒤, 압축을 푼 폴더에서 다음을 실행합니다.

   ```powershell
   py install_project.py --drafts "C:\Users\사용자\AppData\Local\CapCut\User Data\Projects\com.lveditor.draft"
   ```

   예시 경로 대신 **본인 캡컷 설정의 경로**를 사용하세요. 실행마다 새 폴더를 생성하고 원본과 효과음을 복사하며 프로젝트 내부 경로를 연결합니다. 기존 프로젝트와 캡컷 전체 목록 파일은 수정하지 않습니다. 설치 스크립트에는 Python 표준 라이브러리만 필요합니다. 캡컷을 다시 열어 프로젝트를 확인하세요.

> **호환성:** `pycapcut==0.0.4`를 사용한 비공식 초안 생성입니다. 라이브러리는 기능별로 CapCut Windows 8.2 / 9.5 검증 이력을 안내하지만, 이 앱의 생성물을 실제 Windows 캡컷에서 열어보는 검증은 아직 수행하지 않았습니다. 버전에 따라 초안 형식이나 목록 인식이 달라질 수 있습니다. 생성 폴더가 목록에 나타나지 않으면 사용 중인 캡컷 버전과 초안 형식에 맞춘 추가 연동 작업이 필요합니다. SRT는 별도로 가져올 수 있습니다.

## 직접 쓴 대본으로 자막 달기

1. 영상을 선택하고 **자막 문구 가져오기 → 내 대본으로 시간 맞추기**를 선택합니다.
2. 표시된 입력란에 **영상에서 실제로 말하는 순서대로 대본을 붙여 넣습니다.** 최대 8,000자입니다. 줄바꿈·문장 경계를 기준으로 나누고 긴 줄은 38자 이내로 다시 나눕니다.
3. 한국어 영상은 인식 언어를 한국어로 두고 **자동 편집 시작**을 누릅니다. 음성을 로컬에서 인식해 단어 시간을 구한 뒤 대본 문구를 그 시간에 연결합니다. 음성 인식 API 키는 필요하지 않습니다.
4. **자막 탭**에서 문구와 시작·끝 시간을 확인합니다. **시간 확인 필요**가 표시된 자막은 재생해 수정한 뒤 **확인 완료**를 누릅니다. 음성에서 찾지 못한 문장은 자동으로 자막을 만들지 않고 목록에 남깁니다. 필요한 경우 재생 위치를 잡고 **현재 위치에 추가**한 뒤 수동으로 시간을 맞출 수 있습니다.
5. **캡컷 프로젝트 만들기**로 내보내면 선택한 컷을 반영해 자막 시간을 재계산합니다. 대본 문구를 사용하는 SRT와 수정 가능한 캡컷 텍스트 트랙을 생성합니다.

이 기능은 **음성 인식 결과와 대본의 문자를 비교하는 보조 정렬**입니다. 표시되는 일치도는 문자 매칭 비율이며 시간 정확도나 확률이 아닙니다. 단어 내부의 세부 경계는 길이에 비례해 추정합니다. 숫자 표기와 발음이 다른 경우, 대본과 다른 발화, 반복 테이크, 긴 공백은 잘못 연결되거나 누락될 수 있으므로 미리보기로 확인하세요. 발화 순서대로 정렬하며 대본과 다른 영상 순서를 자동으로 재배치하지 않습니다. 대본만으로 음성을 합성하거나 영상 없이 자막 시간을 생성하지 않습니다. 정렬 시 인식 문자는 최대 40,000자까지 지원합니다.

음성 인식에는 `faster-whisper==1.2.1`과 호환되는 `av==16.1.0`을 고정합니다. PyAV 19에서는 오디오 읽기 인자가 제거되어 기존 설치에서 오류가 날 수 있습니다. 업데이트 후 실행 배치 파일이 고정 버전을 설치합니다.

기존 ZIP 버전 사용자는 실행 중인 서버 창을 닫고, GitHub의 `capcut-agent` 브랜치 ZIP을 다시 받아 **새 폴더에 압축을 풀어** `start-windows.bat`을 실행하세요. 기존 폴더는 보관하면 영상·프로젝트·모델 캐시가 보존됩니다. 새 폴더에서는 의존성과 모델을 다시 설치·다운로드할 수 있습니다. 브라우저는 새로고침하세요.

## 원본·편집본·프로젝트로 스타일 등록

1. **원본·편집본으로 스타일 등록**을 열고 이름과 종류(해외 영상 해설형 / 반전형 / 정보 전달형)를 선택합니다.
2. **같은 편집 작업의 프로젝트 폴더 ZIP, 편집 전 원본, 편집 완료 MP4**를 순서대로 선택하고 **예시 분석 · 스타일 저장**을 누릅니다. ZIP은 64MB 이하, 영상은 파일당 4GB / 4시간 이하입니다. 이 웹앱의 한도이며 채팅 첨부파일 전송 한도와 다릅니다.
3. 프로젝트에서 영상·정지 이미지·텍스트·음악·효과음 구간, 자막 위치·크기·색상·스타일과 영상 키프레임 여부를 추출합니다. 원본과 편집본은 최대 120장, 최대 초당 1장으로 화면 유사도를 비교합니다. 대응 시간은 근사 후보이며 정확한 컷·이야기 의미 분석 결과가 아닙니다. 검은 영역을 제거하거나 같은 위치를 비교하는 두 방식을 시험하지만 크롭·확대·오버레이·정지 장면에 따라 틀릴 수 있습니다.
4. 저장한 스타일을 **편집 레시피 → 저장한 편집 스타일**에서 선택한 뒤 새 원본을 분석합니다. 현재는 해설 자막의 대표 크기·색상·세로 위치·기울임/굵기와 자막 분할 목표, 합성 효과음의 제한된 음량만 적용합니다. 고유 폰트·질감·캡컷 전용 자막 효과는 정확히 재현하지 않습니다. 브라우저의 글자 크기는 근사 미리보기이며 최종 크기는 캡컷에서 확인하세요.
5. 반전형·해외 해설형은 기다림과 맥락 보존을 위해 무음·정지 컷을 기본 미선택합니다. 삭제할 구간은 검토 후 선택하세요. 정보형은 기존 자동 컷 기본값을 유지합니다.

**이 단계는 예시 분석·규칙 저장이며 AI 모델 재학습은 아닙니다.** 예시의 제목·대사·컷 시점을 새 원본에 복사하지 않습니다. 예시 여러 개를 자동으로 통합하거나 의미에 맞는 컷·반전 시점·해설을 새로 작성하는 기능은 아직 없습니다. 영상 종류 선택도 장면 이해 모델을 활성화하지 않습니다. 음악·효과음 원본과 PC의 폰트·캐시 경로는 외부에서 읽거나 재사용하지 않습니다.

프로젝트 길이와 편집본 길이가 0.15초 넘게 다르면 경고합니다. 내보내기 범위 또는 프로젝트 버전 차이가 있을 수 있으므로 두 파일을 정확히 같은 타임라인으로 취급하지 않습니다. JSON을 읽을 수 없는 암호화·새 형식은 실패 이유를 표시합니다. ZIP은 디스크에 풀지 않고 필요한 JSON만 읽으며 외부 경로를 따라가지 않습니다.

스타일·프로젝트 ZIP·원본·편집본은 **실행한 PC의 `data/styles/<스타일 ID>/`**에 저장하고 외부 서버에 업로드하지 않습니다. 재실행 후에도 유지됩니다. 서버를 종료한 뒤 해당 폴더를 보관·삭제할 수 있습니다. 분석 중 서버를 재시작하면 중단 오류로 표시하며 다시 등록해야 합니다. 새 폴더에 앱을 설치하면 이 데이터는 자동 이전되지 않습니다.

실제 제공된 **CapCut 9.7.0 프로젝트**의 JSON 읽기와 예시 등록, 스타일 적용·프로젝트 생성은 검증했습니다. **CapCut 9.7.0 베타에서 생성 프로젝트를 여는 동작은 아직 검증하지 못했습니다.** 기존 프로젝트를 보관한 채 별도의 새 프로젝트로 확인하세요. 업로드한 실사용 자료는 GitHub에 포함하지 않습니다.

## 기능과 한계

| 기능 | 동작 |
| --- | --- |
| 무음 컷 | FFmpeg `silencedetect`, 기본 -35dB / 0.7초 이상. 경계마다 0.15초를 남깁니다. 배경음이 있는 구간은 무음으로 분류되지 않을 수 있습니다. |
| 화면 멈춤 감지 | 축소 영상의 `freezedetect`, 기본 1초 이상 거의 같은 프레임이 반복되는 구간. 의도된 정지 장면과 구분할 수 없어 기본 미선택입니다. |
| 자동 자막 | 로컬 faster-whisper, 한국어/영어/자동 감지. 모델 tiny/base/small 선택, 문구·시간 수정 가능. 음성 인식 오류가 있을 수 있습니다. |
| 효과음 | 자막의 감탄·질문·성공 표현에 팝/딩, 컷 전환에 슉을 추천합니다. 전환 추천은 기본 미선택. 직접 합성한 소리로 외부 음원 파일을 쓰지 않습니다. 자유로운 영상 의미 이해 모델은 아닙니다. |
| 캡컷 초안 | 원본을 참조하는 컷 영상 트랙, 편집 가능한 텍스트 트랙, 별도 효과음 트랙. 자동 컷 후 자막·효과음 시간을 재계산합니다. 삭제된 구간의 효과음은 제외합니다. |

프레임 반복이 아닌 짧은 끊김, 누락 프레임, 불규칙한 프레임 간격을 모두 감지하거나 복원하지는 않습니다. 영상 전체를 삭제하는 편집은 거부합니다. 겹치는 컷은 합쳐 적용하며, 겹치는 자막은 다음 자막 시작에서 끝내고 겹치는 효과음은 앞선 항목을 우선합니다. 컷이 자막 중간을 통과하면 동일 문구가 나뉠 수 있으므로 검토하세요.

현재 한 번에 하나의 작업을 처리합니다. 파일당 최대 4GB / 4시간입니다. 다수의 컷·긴 영상은 미리보기 생성이 오래 걸리고 디스크 공간이 필요합니다. 원본·내보내기·모델은 `data/`에 남습니다. 서버를 종료한 뒤 필요 없는 작업 폴더를 삭제할 수 있습니다. 브라우저 새로고침 시 마지막 완료 작업을 다시 불러옵니다. 처리 중 서버를 종료한 작업과 저장 전 수정 사항은 복구되지 않습니다.

## 개인정보와 네트워크

영상 분석과 음성 인식은 실행한 PC에서 수행합니다. 외부 음성 API, API 키, 유료 서비스는 필요하지 않습니다. 최초 설치에는 PyPI, 최초 모델 실행에는 Hugging Face 모델 다운로드가 필요하며 이때 원본 영상·음성은 전송하지 않습니다. 모델을 내려받은 뒤에는 해당 모델을 로컬 캐시에서 재사용합니다. 화면은 외부 CDN이나 글꼴을 요청하지 않습니다.

모델 다운로드가 차단되면 자막 실패 경고를 표시하고 컷 검토·수동 자막·프로젝트 생성은 계속할 수 있습니다. 네트워크를 복구한 뒤 영상을 다시 분석하세요. 클라우드의 제한된 네트워크에서는 `huggingface.co` 및 모델 파일 리디렉션 도메인(`cas-bridge.xethub.hf.co`, `cas-server.xethub.hf.co`, `transfer.xethub.hf.co`, `cdn-lfs.huggingface.co`, `cdn-lfs-us-1.hf.co`, `us.aws.cdn.hf.co`) 허용이 필요할 수 있습니다.

서버는 `127.0.0.1`에만 바인딩하세요. 개인 PC에서 한 사용자가 쓰는 도구이며 인터넷 공개용 인증·권한 기능은 없습니다.

## 개발 및 검증

Linux / macOS에서도 FFmpeg와 Python이 있으면 분석과 초안 생성을 실행할 수 있습니다. 캡컷 열기 확인은 Windows에서 진행하세요.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
.venv/bin/python -m uvicorn agent.server:app --host 127.0.0.1 --port 8765
```

Windows 터미널에서는 `.venv/bin/python` 대신 `.venv\Scripts\python.exe`를 사용합니다. 데이터 위치는 `CAPCUT_AGENT_DATA` 환경 변수로 변경할 수 있습니다.

테스트는 실제 FFmpeg 샘플을 만들어 무음·정지 감지, 중복 컷 합치기, 자막·효과음 타이밍, 미리보기 인코딩, 무오디오 영상, 프로젝트 ZIP, 경로 재연결과 기존 파일 보존, HTTP 업로드부터 다운로드까지 검사합니다. 대본 정렬 테스트는 한국어 단어 시간 자료로 문구 보존, 빠진 문장, 반복 문장, 부분 불일치, 컷 후 시간 이동을 검사합니다. API의 대본 테스트는 음성 인식 출력을 대체한 결정적인 테스트입니다. **음성 모델 추론과 실제 캡컷 열기는 이 자동 테스트에 포함되지 않습니다.**
